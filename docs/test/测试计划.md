## 2. 审批节点

| 单据 | 审批节点（模板） | `demo` 提交时的实际审批人 |
|---|---|---|
| 内部采购申请 PR | 汇报链至部门负责人 | jeffrey |
| 项目 PR | 不审批，直接到采购 | — |
| 采购订单 PO | CFO 确认供应商条件 → CEO；金额 > 300,000 时再加 Chairman | cfo → admin（→ chairman） |
| 项目立项 | 汇报链至 CEO | jeffrey → admin |
| 项目方案 / 交付验收 / 关闭 | CEO | admin |
| 项目询价（报价） | CEO 定利润点 → CFO 确认财务事项（#61） | admin → cfo |
| 项目合同 | CFO → CEO（#63） | cfo → admin |
| 出差申请、出差报销 | 汇报链至 CEO | jeffrey → admin |
| 维保工时申请 / 延长申请 | 汇报链至部门负责人 | jeffrey |
| 销售费用申请 | 汇报链至 CEO | jeffrey → admin |
| 销售费用报销 | 汇报链至 CEO → CFO | jeffrey → admin → cfo |

- 点击顶部 **To do**，直接显示当前账号的待审批、待处理、待修改单据；点行或 Open 进入原单据操作。审批轮到自己才显示，完成后自动移出。采购转 PO、财务确认账单和付款、采购跟踪收货以及销售费用报销过账付款也在同一列表。采购菜单另保留 Purchase Requests to Convert。
- 驳回必须填原因，单据退回草稿；提交人可以撤回；只有管理员能改派审批人。
- 职位任职人在 Settings › Approvals › Positions 修改。CFO 另有 Finance: Bank Reconciliation (CFO) 权限组。修改账号权限后要重启服务（`docker restart mhtt-app`）才生效。
